MTN إضافة/تحديث الخدمات من CC Web Tool أو ملفات Word

📥 الطريقة

اسحب إلى المنطقة أدناه أحد النوعين:

  • صفحات HTML محفوظة من CC Web Tool (من مجلد Webtool/WebTool) — اسحب الصفحة مع ملفات مجلدها _files لالتقاط الصور.
  • ملفات Word (.docx) مثل «الاشتراك بالخط المسبق الدفع.docx» — تُستخرج النصوص والصور تلقائياً.

تُستخرج الخدمة (الوصف + الخطوات + الفيديو + الصور)، ثم اضغط «توليد services.js» واستبدل به ملف data/services.js.
💡 دمج تلقائي: إعادة إرسال نفس الملف تحدّث الخدمة بدل تكرارها.
