# 🇸🇾 MTN Syria — كتيب الخدمات التدريبي

موقع تعريفي تفاعلي يُعرض على **GitHub Pages** لتعريف المتدربين الجدد في MTN Syria
بجميع الخدمات المتوفرة، مع **شرح نصي تفصيلي** و**فيديو توضيحي** لكل خدمة.

> موقع ثابت 100% — HTML / CSS / JavaScript فقط، بدون أي خادم أو قاعدة بيانات.
> تعمل الصفحات مباشرة من القرص (نقرة مزدوجة) أو عبر GitHub Pages.

## ⭐ إضافة خدمة جديدة (الأهم)

افتح ملف **`data/services.js`** وأضف كائنًا جديدًا لقائمة `SERVICES_DATA`:

```js
{
  id: "service-id",          // معرّف فريد باللاتيني (يُستخدم في الرابط)
  category: "c-mobile",      // معرّف التصنيف من CATEGORIES
  icon: "📱",                // أي أيقونة emoji
  title_ar: "العنوان بالعربية",
  title_en: "English Title",
  summary_ar: "ملخص قصير بالعربية",
  summary_en: "Short English summary",
  description_ar: "الشرح التفصيلي بالعربية \n\n فقرة ثانية عبر سطر فارغ",
  description_en: "Detailed English description",
  steps_ar: ["خطوة 1", "خطوة 2", "خطوة 3"],
  steps_en: ["Step 1", "Step 2", "Step 3"],
  video_url: "",             // راجع الأسفل
  time_ar: "10 دقائق"        // الزمن المتوقع (اختياري)
}
```

**أضف/عدّل الفئات** في قائمة `CATEGORIES`:

```js
{ id: "c-mobile", icon: "📱", title_ar: "خطوط الجوال", title_en: "Mobile Lines" }
```

> ✅ بعد التعديل أعد تحميل الصفحة وستظهر الخدمة فورًا.

## 🧮 نظام إدارة المحتوى للموظفين غير التقنيين (الأهم)

**المشكلة:** الموظفون الذين يضيفون الخدمات لا يعرفون GitHub ولا يملكون خبرة تقنية.

**الحل:** مصدران لتحديث الخدمات دون لمس الكود نفسه:
- 📊 **إكسل/فورم** (الطريقة الأسهل للموظفين غير التقنيين) — قالب جاهز يُحول بضغطة زر.
- 🌐 **صفحات CC Web Tool المحفوظة** (طريقة الخدمات الحالية) — اسحب الصفحة ليتبنى الموقع محتواها تلقائيًا.

### خط سير العمل

```
الموظفون (غير تقنيين)                أنت (المشرف)
─────────────────────                ──────────────
أ. الطريقة الأسهل: فورم إضافة خدمة
   tools/add-service-form.html
   → املأ البيانات + زر "توليد بيانات الخدمة"
   → تنزيل ملف "خدمة-جديدة.csv"
ب. أو: قالب إكسل مملوء بالأمثلة
   (Xlsx أو CSV من أداة التحويل)
        │
        ▼
3. يرسلون لك الملف (واتساب/بريد)
   ──────────────────────────►  4. افتح tools/excel-to-site.html
                                  5. اسحب الملف + زر "تحويل الملف"
                                  6. زر "تنزيل services.js"
                                     (وضع "دمج" يحافظ على باقي الخدمات)
                                    │
                                    ▼
                                  7. استبدل data/services.js بالمُولّد
                                  8. ارفعه على GitHub (GitHub Desktop)
                                  9. الموقع يتحدّث تلقائياً ✓
```

> 📖 الخطوات التفصيلية الكاملة (للموظف وللمشرف) مدمجة داخل صفحة الفورم.
> انقر على «كيفية إضافة خدمة على الموقع» في أعلى `tools/add-service-form.html`،
> أو اقرأ ملف [`HOW-TO-ADD.md`](HOW-TO-ADD.md).

### 📋 إرشادات للموظفين (داخل القالب نفسه)

- لا تعدّل **صف الترويسة** (السطر الأول).
- كل خدمة في **صف واحد**.
- **الخطوات:** كل خطوة في سطر مستقل داخل نفس الخلية (Alt+Enter في إكسل).
- **الشرح:** سطر فارغ = فقرة جديدة.
- **الفيديو:** ضع رابط يوتيوب كامل، أو اتركه فارغًا ليرفع لاحقًا.
- **التصنيف:** اكتب رمزًا مثل `c-mobile`؛ لتصنيف جديد املأ الأعمدة الثلاثة الأخيرة.
- **التحديث:** لتعديل خدمة موجودة، أكتب نفس المعرّف (id) وستُستبدل بياناتها.

### 🛠 مميزات أداة التحويل (`tools/excel-to-site.html`)

| الميزة | التفصيل |
|--------|---------|
| 🧾 **توليد قالب Xlsx** | قالب احترافي بألوان MTN + ورقة تعليمات مدمجة |
| 📥 **سحب الملف** | xlsx / xls / csv — بالسحب والإفلات أو الاختيار |
| 🔄 **وضع الدمج** | يضيف/يحدّث دون حذف خدماتك الحالية (الأأمن) |
| 🔁 **وضع الاستبدال** | الملف هو المحتوى الكامل |
| ⚠️ **تدقيق تلقائي** | تنبيه عن المعرّفات المكررة والتقديم الناقص |
| 🛡 **نسخة احتياطية** | زر تنزيل لنسخة من البيانات الحالية قبل أي تغيير |
| 👁 **معاينة** | جدول يوضح كل ما سيُبني قبل التنزيل |
| 🧩 **يعمل بدون إنترنت** | مكتبة SheetJS **محلية** في `tools/vendor/` — لا CDN، لا حظر |

> 💡 الأداة والموقع يعملان **بدون أي سيرفر** — تكفي فتح الملفات مباشرة
> بنقرة مزدوجة (أو عبر GitHub Pages). صارت كل الصفحات تعمل بالكامل
> **بدون إنترنت بعد** تجميع مكتبة SheetJS محليًا داخل `tools/vendor/xlsx.full.min.js`.

### 🌐 إضافة خدمة من صفحات CC Web Tool أو ملفات Word (`tools/html-to-site.html`)

**الخدمات الحالية (10 خدمات)** مستخرجة من صفحتين مصدر:
- صفحات `Webtool/WebTool` المحفوظة.
- ملفات Word مثل «الاشتراك بالخط المسبق الدفع.docx» (نص كامل + صور مدمجة).

لإضافة خدمة جديدة:

1. **من CC Web Tool:** احفظ صفحة الخدمة (Ctrl+S → «صفحة ويب كاملة»)، واسحب **الصفحة مع ملفات مجلدها `_files`** إلى الأداة لالتقاط الصور.
2. **من Word:** جهّز ملف `.docx` يضم الشرح والصور، واسحبه إلى الأداة مباشرة.
3. تُعرض معاينة: العنوان، عدد الأحرف، الخطوات، عدد الصور، والصور المفقودة (إن وُجدت، أعد سحب الملفات الكاملة).
4. اضغط **«توليد services.js (الدمج)»** ثم نزّل الملف واستبدل به `data/services.js`.

> - إعادة إرسال نفس الملف = **تحديث** الخدمة بدل تكرارها (الدمج تلقائي).
> - **الصور** تُضمَّن داخل `services.js` (Base64) — تعمل بدون إنترنت ومن `file://`.
> - رابط الفيديو (يوتيوب/Drive/MP4) يُلتقط تلقائياً إن وُجد — وإلا يبقى **قسم الفيديو** جاهزاً لإضافته لاحقاً.

### ✍️ فورم إضافة خدمة جديدة (`tools/add-service-form.html`)

فورم عربي بسيط للموظف غير التقني:
- حقول جاهزة (اسم، تصنيف، ملخص، شرح، خطوات، فيديو) مع تحقق من النواقص.
- معاينة حية لشكل الخدمة على الموقع.
- زر **تنزيل خدمة-جديدة.csv** — يتحول مباشرة في أداة التحويل (وضع دمج).
- دليل الخطوات التفصيلي مدمج في أعلى الصفحة.

## 🎬 إضافة الفيديو

| المصدر | مثال | ملاحظة |
|--------|------|--------|
| YouTube | `https://www.youtube.com/watch?v=VIDEO_ID` | الأنسب (مجاني + سريع) — ارفع الفيديو بصيغة **Unlisted** |
| YouTube | `https://youtu.be/VIDEO_ID` | صيغة مختصرة |
| Google Drive | `https://drive.google.com/file/d/FILE_ID/view` | رفع خاص، قد يحجب أحيانًا |

### 🖼️ الصور التوضيحية والجداول

- الصور تُضمَّن داخل بيانات `services.js` (Base64) — تُعرض مباشرة بين الفقرات في مواضعها
  **بالحجم الموحّد**، وتُكبَّر بضغطة عليها.
- الجداول (من ملفات Word أو صفحات HTML) تُعرض **كجداول فعلية** بخلفية بديلة الألوان
  في مواضعها الأصلية.
- المصدر: تُلتقط تلقائياً من **ملفات Word (.docx)** أو من **مجلدات `_files`** عند سحبها مع صفحة HTML.
- للحصول على صور الخدمات الحالية: أعد تسليمها كملفات Word (أو اسحب صفحات HTML مع مجلداتها
  `_files` إلى الأداة وولّد `services.js` مجدداً).
| ملف محلي | `assets/videos/service-name.mp4` | ارفعه مع المشروع بجانب الكود |

**توصية:** ارفع فيديوهاتك على YouTube **(غير مدرج - Unlisted)** وضع الرابط،
هذا الأدوم من ناحية السرعة والحجم. **لا ترفع ملفات فيديو كبيرة على GitHub**
(الحد الأقصى للملف 100MB).

إذا تركت `video_url` فارغًا (`""`) سيُخفى قسم الفيديو تلقائيًا.

## 🚀 النشر على GitHub Pages

1. أنشئ حساب على [GitHub](https://github.com) إن لم يكن لديك.
2. أنشئ **Repository جديد** باسم مثل `mtn-training-guide` (Public).
3. ارفع مجلد المشروع كاملًا إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "MTN Syria training guide"
   git branch -M main
   git remote add origin https://github.com/<اسمك>/mtn-training-guide.git
   git push -u origin main
   ```
4. افتح: **Settings ← Pages ← Deploy from a branch ← Main (أو master) ← / (root) ← Save**.
5. سيصبح موقعك متاحًا خلال دقيقة على:
   ```
   https://<اسمك>.github.io/mtn-training-guide/
   ```

> 💡 موقع ثابت لا يحتاج أي إعدادات إضافية — لا دالة خادم ولا بناء.
